# Hero media contract

Hero背景動画はトップページのHeroにのみ使用する。

推奨:
- hero-surf.webm
- hero-surf.mp4
- 6〜10秒程度
- muted / loop / playsinline
- モバイルで過度に重くならない容量
- 文字やUIを映像へ焼き込まない
- 主役は海・サーフボード・パドル/ライディングの動き
- 45〜60歳向けなので若者向け広告のような過剰編集は避ける

動画未配置時はCSS fallbackでHeroを成立させる。

## BOARD TYPES silhouettes (`board-*-final.svg`)

- Generated by `scripts/generate-board-svgs.py` (`python3 scripts/generate-board-svgs.py public/media`). Edit the outline key points there instead of hand-editing SVG paths.
- All five share one viewBox (same scale), so relative board length stays visible.
- Transparent background only; the card provides the background.
- Display rule: `.board-shape-wrap` is flex with a fixed height, the `<img>` uses `height:100%` + `object-fit: contain`. Never `cover`.
- Visual Mobile QA fails if any board image is clipped at 360 / 390 / 430 / 768 / 1280px.
- When an SVG changes, bump the `?v=` query in `src/pages/index.astro`.
