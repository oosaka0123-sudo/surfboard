# Hero media contract

Hero背景動画はトップページのHeroにのみ使用する。

推奨:
- hero-surf.webm
- hero-surf.mp4
- 6〜10秒程度
- muted / loop / playsinline
- モバイルで過度に重くならない容量
- 文字やUIを映像へ焼き込まない
- 主役は海・サーフボード・パドル/ライディングの動き
- 45〜60歳向けなので若者向け広告のような過剰編集は避ける

動画未配置時はCSS fallbackでHeroを成立させる。

## BOARD TYPES plan views (`boards/*.svg`)

- Generated by `node scripts/generate-board-svgs.mjs public/media/boards`. Edit the outline tables in that script, not the SVG paths, then update `src/data/boardTypes.ts` with the printed width/height.
- Each SVG has a TIGHT viewBox (outline + 5 units of stroke margin). Its own aspect ratio is the board's length:width. There is no reserved empty space, so nothing can be cropped.
- Boards are horizontal, tail left, nose right. Transparent background only; the card supplies the background.
- Relative length is restored in CSS: `<img>` width = `--board-len` (length / longest length) of its stage, `height:auto`. Never give the wrapper a fixed height or `overflow:hidden`, and never use `object-fit: cover`.
- Shapes are illustrative category outlines, not any manufacturer's model.
- Visual Mobile QA fails if a board is clipped, distorted, tiny, or if the five proportions are not distinct.
